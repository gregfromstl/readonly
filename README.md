## Getting Started

Readonly is currently in **ALPHA**. Use at your own risk.[^2] 

> [!NOTE]
> You must have ollama installed! Get it here --> [https://ollama.com/download](https://ollama.com/download)

While in development the model is currently set to a local version of `Qwen 3.5`. Install it with ollama with:
```bash
ollama pull qwen3.5
```

Now just clone the repo and run locally with:
```bash
bun install && bun dev
```

And now you're ready to start reading. Stay safe out there!
